# Frutas-Java
Atividade em aula dia 24/10 - Projeto de codigo usando POO

# Como Vai Funcionar
- Pré-cadastro de clientes.
- Cadastro de tipos de banana e quantidades.
- Escolha do cliente pelo terminal.
- Escolha da banana para compra.
- Verificação da quantidade requisitada

## Classes
- Frutas: classe-base.
- Cliente: cadastro e seleção de clientes.
- Banana: lista de bananas e quantidades.
- Principal: execução do sistema.
